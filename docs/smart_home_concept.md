# スマートホーム家電（照明自動化）プロジェクト構想

## プロジェクトの目的
家（各部屋、特にリビング）の照明のオン/オフを完全に自動化するスマートホームシステムを構築する。

## システム構成
本システムは以下の3つの主要コンポーネントで構成される。

1. **人感センサー** (Presence / Motion Sensor)
   - 部屋内の人の有無を検知する
2. **スマートホームハブ** (Hub)
   - センサーからのデータを受け取り、ボットに指示を出す制御の中核
3. **ボット / アクチュエーター** (Bot / Actuator)
   - 物理的なスイッチのオン/オフを操作する

### APIと連携
- ハブおよびボットは、一旦**SwitchBot API**を利用して制御・連携を行う。

## 技術的要件・特徴
- **コストパフォーマンス**: 全体的に安価に構成する。
- **レイテンシー**: オン/オフ操作において、低レイテンシー（高応答速度・低遅延）を実現し、ストレスのない自動化を目指す。（※ユーザー要件の「高レイテンシー」は文脈から「低遅延（高速な応答）」の意図と解釈）

## 推奨デバイス
センサーノードや自作デバイスのマイコンとして以下の使用を検討・推奨する。

- **Raspberry Pi Pico 2**
  - 高性能かつ低コスト
- **ESP32**
  - Wi-Fi/Bluetooth内蔵でIoT用途に最適
  - ディープスリープなどを活用することで**電池駆動**での運用が期待できる

## センサーの選定と検証
検知精度と応答速度の最適化のため、以下の2種類のセンサーを両方試し、比較・検証を行う。

1. **ミリ波レーダーセンサー** (mmWave)
   - 微細な動き（呼吸など）も検知可能で、人が静止している状態での「居座り検知」に優れる。
2. **赤外線センサー** (PIR)
   - 人の大きな動きの検知に優れ、安価で消費電力が少ない。

## 購入済みデバイス
本日（プロジェクト初期段階）以下のデバイスを購入・準備済み。

- **Raspberry Pi Pico 2 W** (Wi-Fi対応モデル)
- **焦電型赤外線センサーモジュール** (焦電人感センサ / PIR)
- **レーダー人感センサー** (FMCW レーダーミリ波モーション検出モジュール DC5V)
